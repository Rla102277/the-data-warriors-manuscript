## Import protocol
1. Upload the actual DOCX binaries unchanged to archive/originals/.
2. Record original filename, SHA-256, size, and source in archive/MANIFEST.md.
3. Never edit archived binaries. Work in manuscript/ and planning/.
4. If multiple files share a name, keep unique identifiers and hashes.
5. Preserve quotations, footnotes, figures, images, and source attribution.
