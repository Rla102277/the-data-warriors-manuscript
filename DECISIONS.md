# Editorial decision log

## Accepted working principles — 2026-10-19
- Use this private GitHub repository as the durable cross-tool source of truth.
- Preserve session context and editorial rationale as files, not only chat history.
- Keep the manuscript independent of any specific AI vendor or software platform.

## Proposed, not yet approved
- Organize around eight books: Earth, Water, Fire, Wind, Void, People, Tools, Practice.
- Use a recurring Living Scroll case study and progressive Sword Drills.
- Target roughly 75,000–90,000 words and 36 chapters.
- Use six named Council roles.

## Decision protocol
For every material decision record: date, status (proposed/accepted/superseded), context, alternatives, rationale, consequences, and affected files. Never silently erase a superseded decision.
